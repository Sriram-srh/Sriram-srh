### 🍽️ SmartMeal QR — Hostel Food Queue Management System
> **Next.js · TypeScript · Supabase · PostgreSQL · Tailwind CSS**

QR-based meal booking and token validation system for hostel food distribution. Replaces manual queuing with contactless digital authentication, real-time tracking, and role-based dashboards for students, staff, and admins.

- Role-based auth (student / staff / admin)
- Real-time QR token generation & scanner verification
- Supabase-backed automated triggers and RLS policies
- Deployed on Vercel
